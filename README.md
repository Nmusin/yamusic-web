# Yandex Music Web Mod

Неофициальный веб-плеер Яндекс Музыки на Node.js (без зависимостей) с авторизацией через официальный Device Code flow.

## Возможности

- **Моя Волна** — бесконечная персональная лента с фидбеком ротора (skip/trackStarted), без повторов
- **Поиск** по всей библиотеке с быстрыми тегами
- **Мне понравилось** — вкладка лайков из аккаунта
- **Вход тремя способами**: код устройства (ya.ru/device), логин/пароль, ручной токен
- Полные треки без 30-секундных превью (подписанные запросы get-file-info + AES-CTR дешифровка на лету)
- Токен хранится в localStorage, кеш профиля (целевая платформа — Android/Chrome, iOS-фолбэки убраны)
- Мобильная адаптация: safe-area, `100dvh`, PWA-мета (адд на главный экран), landscape-режим
- Медиасессия: управление с локскрина/наушников (play/pause/next/prev/seek)
- Замер реального битрейта выдачи сервера (тест качества в профиле)

## Запуск

```bash
node server.js
# PORT=8080 node server.js
```

Открыть `http://localhost:3000`.

## Важно

- Все запросы проходят через этот сервер; токен аккаунта хранится только в вашем браузере и передаётся на этот сервер. Не поднимайте сервис на публичном домене для посторонних людей, если не понимаете последствий
- Ключ HMAC-подписи (`SECRET_KEY`) и OAuth-клиент Яндекса — публичные константы из открытых проектов (`yandex-music-token` и др.), не личные данные

## Структура

```
server.js        — Node/https прокси: auth, search, wave, likes, stream, quality-test
public/index.html — UI (tabs: Волна / Поиск / Лайки / Профиль)
public/app.js    — логика плеера, авторизация, media-session
public/style.css — стили (тёмная тема, mobile-first)
```
