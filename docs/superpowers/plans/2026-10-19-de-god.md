# De-god Implementation Plan (yamusic-web рефакторинг)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Разрезать `server.js` (1198 стр) на bootstrap + lib/routes по домен и `public/app.js` (1995 стр) на 12 ES-модулей без смены поведения, затем написать корневой `AGENTS.md` — единый гайдлайн агентов.

**Architecture:** Backend — CommonJS: `server.js` остаётся entrypoint (~120 строк: createServer, static, dispatch-мапа), хелперы → `lib/*.js`, роуты → `routes/<домен>.js` c каноническим хендлером `handler(req, res, ctx)`. Frontend — ESM: `public/js/*.js` по домену + `main.js` bootstrap; решение билдера: state живёт в одном мутабельном экспортированном объекте `state`, нежели геттер/сеттер на каждую переменную. SW precache дополняется перечнем `js/*.js`, бамп кеша `ym-shell-v3` обязателен в коммите-флипе.

**Tech Stack:** Vanilla Node http (CommonJS), vanilla JS (ES modules), ноль зависимостей, мин Node 20.

**Spec:** `docs/superpowers/specs/2026-10-19-architecture-de-god-design.md` (утверждён; билдер-чек встроен)

## Global Constraints

- Нулевая смена поведения: те же порты (3000 prod-купленный живой; тесты — **`PORT=3459`**), пути, ответы UI, Wave не тронут, rotor-фидбек одним местом.
- Ноль npm-зависимостей, ноль build-степа. Никакого TS/bundlers.
- Никогда не коммитить `.env`, `tasks.do_not_push_this.txt`; Conventional Commits).
- Вызов API Яндекса: только через `yandexRequest`/`httpsPostForm`, `family:4`, form-urlencoded где было.
- После мутаций лайков — `invalidateApiCache("/likes/...")` (переносится как есть).
- Коммит-гранича: каждый commit = тестируемое состояние (смок старого кода допустим по порядку D4 spec).
- Worktree-работа изолированно от мастера; merge по явному согласию владельца.

## Review Focus

1. **Поте́ря привязки глобалей при переезде (TDZ/undefined):** поведение «мини-плеер после перезагрузки предлагает трек в паузе» меняется только если модуль недо-переносится. → Task 9 смок: рестарт сессии (чеклист D5:6).
2. **Цикл ESM-импортов:** модуль вызывает чужое на top-level → ReferenceError к моменте вызова. → Task 9: правило «cross-вызовы только внутри хендлеров/async» должно быть видимо во всех `js/*.js` (grep top-level вызов в каждом).
3. **SW stale-оболочка:** после флипа старый app.js кешируется → бамп `ym-shell-v3` обязателен в том же коммите, что флип. → Task 9: grep `ym-shell-v3` в sw.js + precache перечни всех `js/*.js`.
4. **Range/декрипт стрима:** перенос инварианта range quaш `ctrDecipherAt` → Task 5 смоку: HEAD/Range по /api/stream, код 206 на partial.
5. **rotor-фидбек потеряется:** «одним местом» после переезда — в `routes/wave.js`. → Task 4: grep `rotor/feedback` — ровно одинusiness роут-файл.
6. **Invalidate-кеш после мутаций лайков:** правильно после удаление/обновение → Task 6 смоку: мутация → `invalidateApiCache("/likes/tracks")` существует в `routes/likes.js`.
