# Comfort Pack: PWA, память сессии, действия на треке, экран трека

Дата: 2026-10-19 · Статус: черновик (ждёт подтверждения владельца)

## Зачем

Плеером пользуются **только с телефона** (владелец подтвердил). Четыре подтверждённые
дыры удобства + новая заявка «увидеть, кто автор»:

1. «Добавить на главный экран» существует только в виде мета-тегов: нет `manifest.json`,
   иконок и service worker — офлайн-открытие даёт белый экран.
2. Ничего не живёт между открытиями: перезагрузка вкладки теряет очередь, позицию,
   антиповтор волны. Токен сохраняется, контекст — нет.
3. У трека в списках (Поиск/Лайки/Подборки) нет действий: тап = играть, всё.
4. Когда очередь (плейлист/подборка) заканчивается, код молча запускает Мою Волну —
   контекст украден без спроса.
5. Н негде посмотреть детали трека: кто автор, альбом, длительность.

## Язык дизайна (решение владельца)

«Минимализм. AMOLED + Material You» — применяется ко всему новому UI:

- AMOLED: чистый чёрный `#000` для фонов (вместо `#121212`/`#181818`).
- Material You: скруглённые листы/меню (16–24dp радиусы), bottom sheet вместо модалок,
  акцент `#ffcc00` остаётся.gridy，динамический цвет — НЕ делаем (минимализм,
  без экстраций), типографика существующая.

## Цели

- **PWA по-честному.** `public/manifest.json` (name, short_name, theme `#000`,
  display `standalone`, icons). Иконки — плоская жёлтая молния на чёрном (SVG,
  `sizes: "any"`; PNG не строим — без сборочных зависимостей, tradeoff: старые
  ланчеры без SVG-иконок покажут заглушку).
- **Service worker** `public/sw.js`: network-first для оболочки (`index.html`,
  `app.js`, `style.css`) c кеш-фолбэком при отсутствии сети, cache-first для
  иконок/манифеста; `/api/*` и `/api/stream` — всегда сеть. `skipWaiting +
  clients.claim`, чтобы обновлённый клиент не жил на старом `app.js`.
  Регистрация в `app.js`. Инвалидация версионированием имени кеша.
- **Память сессии.** `localStorage('ym_session:'+tokenHash)`: ключ **на токен** —
  при выходе из аккаунта сессия не стирается, а ждёт того же аккаунта
  (решение владельца 2026-10-19). Урезанная очередь (id/title/artists/
  album/albumId/coverUri/durationMs, cap ~100), `queueIndex`, источник
  (`wave|smart|playlist|search|likes` + `radioSessionId`), `playedTrackIds`
  (cap 200), позиция текущего трека (сохранение по `timeupdate` раз в ~5 c).
  При открытии: очередь восстанавливается **тихо**, автостарта нет; мини-плеер
  показывает последний трек в состоянии «пауза». Восстановленная сессия при
  истёкшем токене — как гость (30 c превью), плашка уже есть.
- **Действия на треке.** Лонг-пресс (удержание ~400 мс) по любому треку в списках
  открывает bottom sheet с действиями: Полный toggle лайка («Добавить лайк» /
  «Убрать лайк»), «Следом» (вставить после текущего в очередь), «О треке»
  (…см. ниже).
  Снятие лайка **возможно** (проверено live 2026-10-19): отдельный эндпоинт
  `POST /users/{uid}/likes/tracks/remove` + form `track-ids=<id>` — прошлые
  14 форм не включали этот action-путь. Серверный `/api/like` должен
  поддержать `remove=1` через него и инвалиди́ровать кеш `/likes/tracks`.
- **Экран трека.** Bottom sheet: обложка (400x400, tap — закрыть), название,
  артисты, альбом, длительность, кнопка лайка (полный toggle), кнопки «Следом»
  и «Слушать». Открывается лонг-прессом («О треке») и тапом по инфо-зоне
  мини-плеера. Тап по треку в списке как раньше — играет немедленно
  (минимализм: не добавляем шаг).
- **Конец очереди = конец.** Fallback `startWave()` для 来源 `wave` сохраняется
  (там это семантика волны). Для остальных источников: остановка с плашкой
  «Очередь закончилась» (заменяет содержимое области волны; мини-плеер жив)
  + кнопка «Включить Мою Волну». Никаких автоматических пересадок.
- **Сердечки в списках** — batch-статус через существующий `/api/like-status`
  (сервер уже умеет), чтобы соответствовать реальному состоянию.

## НЕ-цели (по согласию владельца)

- Свайп между вкладками, drag-перемотка.
- Офлайн-кеш треков/данных API.
- Динамическая палитра Material You из обложки.
- Любой отдельный UI для десктопа (только остаётся как есть).

## Ограничения

- Ноль npm-зависимостей; vanilla JS/ES5-class стиль существующего `app.js`.
- Ничего не отправляем наружу нового; все API-запросы через собственный сервер.
- Не ломать Wave-режим: rotor-фидбек и продолжение сессии без изменений.
- `.env` / личные токены не трогаем; хранение — только `localStorage`.

## Оставлено строителю

- Точная CSS-реализация (переменные, тени, анимации sheet'а) — по вкусу строителя
  в рамках «AMOLED + Material You» и существующей `style.css`.
- Мелкая маршрутизация событий лонг-пресса (совместимость с существующим
  `addEventListener("click")` и скроллом списков).
- Формат ключа `ym_session` и защита от повреждённых данных (try/catch).

## Открытые вопросы строителя

Нет. Все три ранее заданных вопроса закрыты ответами владельца:
иконка — плоская молния SVG (минимализм); «Следом» — после текущего;
тап играет сразу, карточка — через лонг-пресс и мини-плеер.
«Токен-ключ сессии» и «unlike возможен» подтверждены 2026-10-19.
